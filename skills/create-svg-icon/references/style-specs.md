# Linear and filled baseline systems

Use these as starting points. Freeze the adapted values before generating the PNG sheet, then keep them unchanged through vector reconstruction.

## Linear

- Grid: 24 units; live area about 80%; roughly 10% padding.
- Stroke: 2 units by default; one weight across the family.
- Caps and joins: rounded for friendly/refined products, square or mitered only when brand language calls for it.
- Corners: one small-radius vocabulary.
- Angles: prefer 45-degree increments.
- Detail: one core idea and no more than 3–4 meaningful elements.
- Fill: none. A user-requested accent must remain lighter and smaller than the defining stroke.
- Perspective: flat and front-facing.
- Shadow: none.
- Default color: one locked dark hex, replaceable with a supplied brand token.

Linear icons suit content-dense interfaces, inactive navigation states, tools, settings, and refined minimal products. At about 16 px, simplify aggressively and validate pixel alignment.

## Filled

- Grid: 24 units; live area about 80%; optical sizing required.
- Silhouette: one solid fill with transparent interior holes.
- Corners: one soft radius across the family.
- Angles: prefer 45-degree increments.
- Detail: one core idea and no more than 3–4 shapes.
- Outline: none unless the user explicitly requests a hybrid system.
- Perspective: flat and front-facing.
- Shadow and gradient: none by default.
- Color: one locked brand hex across the set.

Filled icons suit active navigation states, sparse high-priority entry points, automotive or glanceable interfaces, and small sets that need strong visual weight. Avoid large dense grids of heavy filled glyphs.

## Shared family rules

- Give each meaning a familiar, unambiguous metaphor before adding personality.
- Reuse one canonical head, plus, document, frame, spark, or other recurring part.
- Match visual area rather than mathematical bounds.
- Keep defining elements visually heavier than decoration.
- Repeat a restrained brand motif only when it does not weaken recognition.
- Test the entire family together, not one icon at a time.
